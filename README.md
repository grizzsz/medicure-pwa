# MediCure — Medication Adherence & Guidance App

A Progressive Web App (PWA) designed to help patients manage and track their medication intake.

## Live App
[Open MediCure](https://your-netlify-url.netlify.app)

## How to Install on Phone
1. Open the live link in **Google Chrome**
2. Tap the **3-dot menu (⋮)**
3. Tap **"Add to Home Screen"**
4. MediCure is now installed like a real app 

## Features
- Add and manage medications
- Set reminders with custom times
- Mark doses as taken or skipped
- View medication adherence statistics
- Calendar view of intake history
- Emergency contact with call and SMS
- Voice input (Speech Recognition)
- Dark mode and text size settings
- Works offline (PWA)

## Built With
- React (JavaScript)
- Vite
- Web APIs (Notifications, localStorage, AudioContext, SpeechRecognition)
- Netlify (Hosting)
- Progressive Web App (PWA)
